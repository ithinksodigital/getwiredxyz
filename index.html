Features

What you get when Wired runs in your menu bar.

Status at a glance

RJ45 icon in the menu bar shows connected or disconnected. Active interface name (e.g. en0) when wired. No extra window, no dock icon.

Connection details

Quickly check whether Ethernet is connected and see current interface details directly from the menu.

Interface details

From the menu: IPv4, IPv6, MAC, vendor, model, default route. Copy IP or MAC to clipboard with one click.

Quick checks

Ping gateway or 8.8.8.8 from the menu. Launch at login so status is always there after reboot.

Requires macOS 13+. Best tested on macOS Tahoe.

How it works

Up and running in under a minute.

1

Download the DMG

Grab the latest release from GitHub. No installer, no App Store, no account required.

2

Open and run

Drag Wired to Applications and launch it. macOS may ask for network permissions on the first run.

3

Always in your menu bar

Ethernet status is live in your menu bar. Enable "Launch at Login" to keep it across reboots.

Privacy first

Everything stays on your Mac

No analytics inside the app. No cloud sync. No account. No background services outside your session. Wired reads only the network interfaces macOS exposes locally — nothing leaves your machine.
